# Smallest real-Google archive validation (proposal only)

No live action was taken to produce this plan. Obtain the existing workflow's authorization before creating disposable Google files or editing the project's saved source. Do not expand OAuth grants or deploy this candidate as part of validation.

## What a manual export proves

Opening a synthetic Totals sheet in Sheets and manually choosing PDF/fit-to-one-page can establish a readable eight-store layout and full heading. It does **not** establish that the candidate's code produces that layout, captures evaluated formulas correctly, sends the right export parameters, creates one PDF, or handles inherited access/retries. It is supplementary evidence, not sufficient candidate validation.

## Scope of evidence

This demonstrates the real candidate's snapshot/export/file/ACL path without switching a live month. Full `startMonth` transaction behavior, admitted-scan timing, failures and process-restart recovery are separately regression-tested offline. A real end-to-end rollover requires an additional isolated harness using entirely synthetic state; do not claim the archive-only smoke test proves a production month switch.
